# OmniSnag — Chrome 媒体嗅探与链接提取扩展（Manifest V3）

> 专业级 Chrome / Edge 扩展：流媒体嗅探（m3u8 / mpd / fMP4·m4s / ts / mp4）、防盗链凭据捕获与传参下载、
> 分片按作品归并去重、批量采集全集、VPS 远程下载桥接（主导路径）。

当前版本 **1.8.0** ｜ 源码目录 `extension/` ｜ 零构建工具，可直接「加载已解压的扩展程序」
开源仓库：<https://github.com/dawencaixukun/omnisnag>

---

## 🌟 核心功能

### 1. 🎥 流媒体嗅探

- **双重拦截**：`chrome.webRequest` 网络层监听 + 页面 MAIN 作用域 Hook（拦截 `fetch` / `XMLHttpRequest` / `HTMLMediaElement.prototype.play`）。
- **嗅探黑名单**：维护域名黑名单（设置面板内），命中的域名跳过嗅探。支持手动添加与从 URL 批量导入（自动提取域名、去重）；条目匹配自身及全部子域，媒体域名或来源页面域名任一命中即拦。详见下方「嗅探黑名单」一节。
- **格式识别**：`.m3u8`(HLS)、`.mpd`(DASH)、`.ts`、`.mp4`、`.m4s`、fMP4 初始化段、`.flv`、`.webm` 及音频流。
- **判定按 pathname 而非整串 URL**：避免查询串干扰（例如 `clip.mp4?ts=123` 曾被误判为 TS 分片）。
- **按「作品」归并去重**：
  - 同一视频的 master、各清晰度变体、初始化段、全部分片归到**同一个条目**下；
  - 去重键忽略签名 / `tag` / 时间戳等 37 类易变参数，同一文件不会因签名变化被反复添加；
  - 分片折叠是**幂等**的：同一个视频播放多次，分片计数不会虚增。
- **可播放性标注**（不夸大能力，明确告知限制）：
  - ⛔ 初始化段（`EXT-X-MAP` 指向的 `.mp4`）仅含 moov 元数据，**不能单独播放**；
  - ⚠️ 仅视频轨（无声音）/ 仅音频轨（无画面）—— 分开的轨需要一起合并；
  - ⛔ 流片段不能单独另存为完整视频。
- **内存保护**：单标签页条目上限 300，优先淘汰分片。

### 2. 🔐 防盗链凭据捕获与传参下载

- **只捕获真实发出的请求头**：通过 `webRequest.onBeforeSendHeaders`（含 `extraHeaders`）截获浏览器**实际发送**的 `Referer`、`Origin`、`User-Agent`、`Cookie`、`Authorization`。
- **不主动扫站内 Cookie**：刻意**不**调用 `chrome.cookies` 去捞同域全部 Cookie。注入浏览器没发过的 Cookie 会让下载命令变脏，部分服务器反而拒绝。绝大多数 CDN 只需 Referer + UA。
- **标签三档如实显示**：🟢 已捕获鉴权凭据（Cookie / Authorization）｜🔵 仅 Referer 防盗链 ｜⚪ 无特殊防盗链。

### 3. ⬇️ 两条下载出口

1. **浏览器内下载（Offscreen Document）**
   - 多切片并发拉取 + 重试，**手动限速单旋钮**（防止高频请求触发站点风控）；
   - Web Crypto API 完成 **AES-128 切片解密**；
   - **TS → MP4**：经 `mux.js` 无损转封装；
   - **fMP4 / CMAF 分片**（`.m4s`、带时间段的 `.mp4`）按规范**直接字节拼接**（初始化段置于最前）—— 这类分片已是 MP4 盒子，硬灌进 mux.js 会产出损坏文件；
   - 支持中途**取消**（taskId → AbortController）。
2. **⚡ 传参导出 CLI**：自动拼装带完整鉴权头的命令行，覆盖 **N_m3u8DL-RE**、**FFmpeg**、**cURL**、**Aria2** 与原始 Headers JSON。

### 4. ☁️ VPS 远程下载桥接

接口契约为固定前缀 `/api/ext/m3u8`（不可配置），鉴权头 `X-Ext-Token`：

| 端点 | 作用 |
|---|---|
| `POST /resolve` | 探测播放列表 → 返回 `master`（变体列表）或 `media`（可直接下） |
| `POST /submit` | 提交下载 → `{ task_id, duplicate }` |
| `GET /tasks` | 任务列表（进行中优先） |
| `POST /cancel` | 取消任务 |
| `POST /retry` | 重试（续传已下分片） |

- 单条卡片走「**探测 → master 弹清晰度选择 / media 弹信息摘要 → 提交**」；
- 任务看板显示进度条、速度、分片数、成品大小，可取消 / 重试；
- 轮询**仅在存在 queued/running 任务时**每 2 秒执行，空闲自动停表。

### 5. 🕘 历史记录（按域名隔离 + 写入时压缩）

- **按来源网页域名分桶**，切换站点只显示该站历史，互不串台（同一网站的多 CDN 仍聚在一起）。
- **四层压缩全部发生在写入时**（不依赖渲染层，换 UI 也不会失效）：
  1. 分片折叠进所属播放列表（记 `tsCount` / `tsBytes`，且幂等）；
  2. URL 归一化判重（仅签名不同视为同一条，更新直链）；
  3. 单域名上限 200 条 / 域名词上限 120；
  4. 凭据截断 512 字符。
- 实测压缩比可达数千比一（一次播放动辄上千次请求 → 数十条记录）。
- 「清空本站历史」只影响当前域名；本地立即清空并打 15 秒墓碑，避免轮询把旧数据拉回。

### 6. 🚫 嗅探黑名单

- **位置**：设置面板「🚫 嗅探黑名单」分组。
- **作用**：命中的域名**跳过嗅探**，不再产生媒体条目、历史记录与角标计数。
- **两种录入方式**：
  1. **手动添加**：输入框填域名（或 URL，自动提取域名），点「添加」或按 Enter；
  2. **从 URL 导入**：文本框粘贴任意行数的 URL / 域名列表（每行一条），点「导入」，自动提取域名、剔除无法识别的行、合并重复项，并汇总「新增 / 重复 / 无法识别」条数。
- **匹配语义**：条目按**根域**匹配（`example.com` 命中自身及全部子域）；**媒体资源域名**或**来源页面域名**任一命中即拦。
- **归一化**：导入条目自动转小写、剥端口、去 `*.` 通配前缀与尾点；非法条目会被拒绝并计数。
- **生效范围**：仅对**之后**的嗅探生效；黑名单修改通过 `storage.onChanged` 即时同步到后台，无需重载扩展。已捕获的列表条目不受影响（可用「清空列表」手动清掉）。
- **数据**：存于 `chrome.storage.local` 的 `sniffBlacklist`，随扩展其他设置一同持久化。

### 7. ☁️ VPS 远程下载（主导路径）

- 媒体卡片与批量采集面板的**主按钮**是「☁️ 推送下载」：先由服务端探测播放列表（master 会弹出清晰度选择），再提交服务端下载。
- 契约：`POST {BASE}/api/ext/m3u8/resolve|submit|cancel|retry`、`GET /tasks`，鉴权头 `X-Ext-Token`。
- 设置里配置服务器地址与 Token；服务端未部署时按钮会明确报错，不会静默失败。
- **浏览器内下载（mux.js 转封装）保留为备用路径**，受内存与功耗限制，适合小文件。

### 8. 📺 批量采集全集

- **点击模式**：按正则（默认 `^V\d+$`）自动逐集点击，适用于 `V1~V99` 这类选集列表；
- **接口模式**：直接抓列表页与播放页源码解析 m3u8，**不点击、不播放**；
- 支持起始 / 结束集范围、每集等待时间，采集结果可复制 / 导出 / 批量推送 VPS。

### 9. 🎛️ 页内交互与界面

- **悬浮小圆钮（FAB）**：始终位于最上层（`z-index` 最大），可拖拽且位置持久化；点击唤出页内抽屉面板。
- **面板内自定义弹窗**：全部 `alert` / `confirm` 已替换为自绘弹窗与轻提示条，与暗色主题统一，且**不阻塞 JS**。
- 层级约定（实测值）：侧边栏内 下拉菜单 `50` < 模态 `100` < 链接悬浮钮 `400` < 链接叠加层 `500` < 确认框 `600` < 提示条 `700`；页内悬浮圆钮恒为 `2147483647`（最大值）。
- 四个关闭路径：确定 / 取消 / 点遮罩 / `Esc`。

## 🚀 安装

1. 地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）；
2. 打开右上角 **开发者模式**；
3. 点 **加载已解压的扩展程序**，选择本项目的 `extension` 文件夹。

也可以直接解压 `OmniSniffer-v1.7.6.zip` 后加载。
也可以从 [Releases](https://github.com/dawencaixukun/omnisnag/releases) 下载打包版 `OmniSnag-v1.8.0.zip`，解压后按上述步骤加载。

## 💡 使用要点

1. **唤出面板**：点击工具栏图标 → 在页面右下角唤起悬浮圆钮与抽屉；也可在 Chrome 侧边栏菜单打开完整侧边栏。
2. **嗅探与下载**：在视频网站播放视频，列表实时出现条目。
   - `⬇️ 浏览器下载` — 后台并发下载 + 解密 + 合并，保存到下载目录；
   - `⚡ 传参导出(CLI)` — 复制已填好 Cookie / Referer 的命令行；
   - `🧩 合并N片为MP4` — 把折叠的分片合并为单个文件；
   - `☁️ 探测并推送` — 交由 VPS 下载（需先在设置里填地址与 Token）。
3. **看清单个条目能不能用**：先看标签——标了 ⛔ / ⚠️ 的条目**不能单独播放**，需要合并或与另一条轨配对。
4. **VPS 设置**：填服务端地址与 `X-Ext-Token`（服务端 `.ext_token` 文件里的值），开启后任务看板才出现。
5. **下载参数**：设置里可调并发数、重试次数与**请求间隔（手动限速）**。遇到站点风控时把间隔调大。

## 📋 权限说明（10 项）

| 权限 | 用途 |
|---|---|
| `webRequest` | 监听媒体请求与真实请求头 |
| `declarativeNetRequest` | 请求头注入（下载时补 Referer 等） |
| `storage` | 设置与历史持久化 |
| `cookies` | 读取媒体请求实际携带的 Cookie（不主动扫站内全量 Cookie） |
| `sidePanel` | 侧边栏面板 |
| `scripting` | 注入内容脚本（FAB 兜底注入） |
| `activeTab` | 获取当前标签页信息 |
| `downloads` | 保存下载文件 |
| `tabs` | 标签页切换与标题获取 |
| `offscreen` | 离屏文档执行下载 / 解密 / 合并 |

## ⚠️ 已知边界

- **不限速可能触发风控**：默认已启用 1000ms 间隔，账号风险自担。
- **AES-128** 已支持；**SAMPLE-AES / Widevine 等 DRM 内容不支持**，也不会去绕过。
- **单轨流需要配对**：音视频分开的 HLS 流（如 X/Twitter）单独下一条只有画面或只有声音，需合并两条轨。
- **不主动扫站内 Cookie**：这是刻意设计，避免污染下载命令。
- 部分使用复杂 DASH / 自定义分片命名的站点，可能需要补充专属归并规则。
